# Summit Ridge Roofing — Demo Website

A demo website for a fictional roofing company in Dallas, TX, USA.
Built as a sample to show real roofing companies what a modern website can do for them.

- Live site: https://cinedropsasmrai-eng.github.io/summit-ridge-roofing/
- Single-file site (`index.html`) — HTML, CSS and JavaScript only, no build step.
- Sections: hero with free-inspection form, services with prices, offers, why-choose-us, 4-step process, before/after slider, project gallery, reviews carousel, storm/insurance help, financing, service areas, FAQ, contact.
- All company details (phone, address, licence, reviews) are fictional placeholders for demo purposes.
